# Pixel Me This: social post images

Public images for scheduled Pixel Me This social posts, served by GitHub Pages so Buffer can fetch them (Buffer's API has no upload endpoint).

- Only finished, approved post images go here: `images/<batch>/<file>`.
- Nothing private: no client documents, no unpublished client facts, no keys or credentials.
- Managed by `/social-calendar` from `08 Social/` in the Pixel Me This folder.
